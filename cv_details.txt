Project Name: Cyber Swarm Command Center (or Swarm Robotics Tactical Simulation)

Tech Stack Used:
- Frontend: HTML5, Vanilla JavaScript (ES6), CSS3 (Glassmorphism, Cyberpunk UI design)
- Graphics & Audio: HTML5 Canvas API, WebAudio API (Procedural Synthesizer)
- Hardware/Firmware (if applicable): C++, Arduino IDE (ESP32)
- Deployment: Vercel, Git/GitHub

What it does:
A decentralized swarm robotics simulation and command center. It visualizes and manages autonomous robotic nodes operating in an arena. The system features a peer-to-peer task auctioning algorithm, priority-based task queueing, dynamic spatial obstacle avoidance, and battery lifecycle management. The interface is a highly interactive, modern Sci-Fi HUD providing real-time telemetry, visual radar sweeps, and audio feedback.
